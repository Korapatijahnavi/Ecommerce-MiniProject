E-Commerce Mini Project

An Android grocery shopping application developed as part of an Android Internship E-Commerce Mini Project. The application follows a Java + XML + MVVM architecture and includes product browsing, category filtering, product details, cart management, checkout, and a simulated payment flow.

Product data is retrieved from the free DummyJSON REST API.

## ✨ Features
  ### 🔐 Authentication
      1) Splash screen with session checking
      2) First-launch flow: Splash → Intro → Login → OTP
      3) Subsequent launches skip login when a session exists
      4) 10-digit mobile number validation
      5) Numeric keyboard for mobile number input
      6) 4-digit static OTP verification
      7) Mobile number passed between screens using Intent extras
      8) Session management using SharedPreferences

      
   ### 🏠 Home
    1) Special offers displayed using a horizontal RecyclerView
    2) Categories displayed using a 4-column grid
    3) Best deals displayed using a 2-column grid
    4) Clickable "View All" options
    5) Bottom navigation
   ## 🛍️ Products
    1) Grocery product listing
    2) Search functionality
    3) Category filtering
    4) Reusable category tabs
    5) Product grid using RecyclerView
    6) Product quantity controls    
   ## 📦 Product Details
    1) Product images
    2) Price and discount information
    3) Product rating
    4) Stock availability
    5) Warranty information
    6) Shipping information
    7) Product description
    8) Add to Cart functionality
   ## 🛒 Cart
    1) Add products to cart
    2) Increase/decrease quantity
    3) Remove products
    4) Live subtotal and total calculation
    5) Cart item count/badge
    6) Shared cart data across screens
   ## 🚚 Checkout
    1) Delivery details form
    2) Name, mobile number, and address validation
    3) Address type selection
    4) Payment method selection
    5) Order confirmation flow
